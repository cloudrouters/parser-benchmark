---
description: Independently review current code changes for bugs, regressions, and violations of project requirements.
---
1. Check the Git status and review all staged, unstaged, and relevant untracked files.
2. Compare the changes against project requirements, existing rules, and surrounding code.
3. Identify concrete bugs, regressions, security vulnerabilities, and gaps in test coverage.
4. Run relevant existing tests and code quality checks when necessary.
5. Do not modify files, fix identified issues, create commits, or push changes to the remote repository.
6. Report findings in Russian, ordered by severity. For each finding, specify the file and, where possible, the line number, describe the issue, and explain its impact. Distinguish confirmed defects from potential risks.
7. If no issues are found, explicitly state that and list any checks that could not be performed.
